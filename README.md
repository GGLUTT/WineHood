# WineHood

A responsive web application for browsing and exploring fine wines. This project showcases a collection of wines with detailed information, allowing users to compare features and make informed purchasing decisions.

![WineHood Screenshot](https://i.imgur.com/d3vK2q2.png)

## Live Preview

You can view the wine catalog here: [DEMO LINK](https://github.com/GGLUTT/WineHood)

## Design Reference

The application follows a clean, user-friendly interface design with intuitive navigation and detailed product cards. The design prioritizes ease of use while providing comprehensive information about each wine.

## Getting Started

### Viewing Online

Visit the [live demo](https://github.com/GGLUTT/WineHood) to view the wine catalog in your browser.

### Running Locally

1. Clone the repository:
```bash
git clone https://github.com/GGLUTT/WineHood.git
```

2. Navigate to the project directory:
```bash
cd WineHood
```

3. Install dependencies:
```bash
npm install
```

4. Start the development server:
```bash
npm start
```

5. To build for production:
```bash
npm run build
```

6. To run tests:
```bash
npm test
```
